# 🚀 Gulfi Chat — Friendly, Intelligent, Multilingual AI Assistant

> **Gulfi Chat** is an intelligent, friendly AI chatbot created strictly following the **Gulfi Chat Master System Prompt**. It communicates naturally in **English, Tamil (தமிழ்), and Tanglish**, provides accurate **India Standard Time (IST)**, helps with **Exam Prep (2/5/13 Marks)**, writes clean code, drafts full project blueprints, and works **100% offline out-of-the-box with ZERO API key required**!

---

## 🌟 Key Features

1. **🤖 True Gulfi Identity & Tone**
   - Warm, friendly, approachable personality with light emojis (😊, 👍, ❤️, 💡, 🔥).
   - Speaks fluent **Tanglish**, **Tamil**, and **English** ("*Ennaku HTML basics sollu da*" ➔ "*Sure da 😊 HTML na website oda basic skeleton...*").

2. **⏰ Live IST Clock & Calendar (Asia/Kolkata UTC+05:30)**
   - Header features a live real-time ticking IST clock and date.
   - Accurately answers questions like *"Current time enna?"*, *"What time is it?"*, *"Today's date"*, *"Tomorrow"*, *"Yesterday"*.

3. **🎓 University Exam Power Mode**
   - **2-Mark Answers:** Concise formal definition and core formula/point.
   - **5-Mark Answers:** Concept overview, core characteristics, working flow, and real-world example.
   - **13-Mark / Big Questions:** Complete academic structure with Introduction, Definition, Architecture/Diagram, Working, Advantages, Disadvantages, Applications, and Conclusion.

4. **💻 Coding & Web Development Support**
   - Supports HTML, CSS, JavaScript, Python, SQL, Java, C, C++, and React.
   - Syntax-highlighted code blocks with macOS window dots and **One-Click Copy** buttons.
   - Step-by-step instructions on where to paste and how to run the code.

5. **🚀 Project Blueprints & Ideas**
   - Generates production-ready blueprints for College, Hackathon, and Final Year projects.
   - Includes Problem Statement, Objectives, Tech Stack, Database schemas, Architecture, and Roadmap.

6. **✨ Creative Studio**
   - Instant Instagram captions (Aesthetic, Tamil mass, chill vibes), LinkedIn posts, Bios, and Midjourney/AI prompts.

7. **🎙️ Voice Input & Text-to-Speech (TTS)**
   - Click the **Microphone** to speak in Tamil/English!
   - Click **Listen** on any message to hear Gulfi speak aloud.

8. **🛡️ 100% Zero-API Requirement**
   - Ready to run immediately without needing an API key or installation.
   - Built-in intelligent conversational engine + optional external AI settings (Groq/OpenRouter/Ollama) for advanced power users.

## 🚀 How to Run Locally

### Option 1: Native Node.js Server (Recommended)
Open your terminal in this directory and run:

```bash
node server.js
```
Then open your browser at:
👉 **`http://localhost:3000`**

### Option 2: Double-Click Directly
You can also directly double-click `index.html` in Windows Explorer to open it in Chrome, Edge, or Firefox!

## 📁 Project Architecture

- **`index.html`** — Modern semantic structure, glassmorphic UI, sidebar drawer, and settings modal.
- **`style.css`** — Custom CSS design system with Dark/Light mode, neon accents, micro-animations, and responsive layouts.
- **`gulfi-brain.js`** — Gulfi Chat's core intelligence, language detection, live IST date calculations, and response engine.
- **`app.js`** — UI controller, Web Audio sound synthesis, Web Speech API, markdown rendering, and local chat storage.
- **`server.js`** — Lightweight zero-dependency Node.js HTTP server.
- **`assets/gulfi_avatar.jpg`** — Official high-resolution 3D mascot avatar for Gulfi AI.
